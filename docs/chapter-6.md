# 第六章 · 动物救助站

给 3 岁孩子的引导式语音冒险，艾莎和团团带孩子照顾六个新朋友。家长选关、允许麦克风后，13 步自动连成三幕，预计 5～8 分钟，按孩子的开口节奏变化。

按用户提供的主题顺序，本章参考 **Big Fun 1 · Unit 7 Animals**。词汇和剧情为游戏自主编写，并非教材原文复刻；游戏章号与教材单元号分别记录。

教学词汇：cat、dog、rabbit、bird、duck、fish；结尾使用 animals 指代动物朋友。核心句型：**I see a ___. / I like animals.**。没有其他主题的战斗咒语、计时或发音分数。

重复词承接新的故事动作：cat 从叫醒到躲猫猫再到梳毛，dog 从玩球到甩水，rabbit 从跳跃打招呼到安睡，duck 从水塘划水到营地跳舞。身体动作只是画面反馈，系统不检查孩子是否真的跳或触摸身体。

三个环境从地点、颜色和时间上区分：薄荷黄房车救助站、青绿水塘剖面、紫色月光树屋营地。小鱼始终出现在水中：水塘的水下区域、充水观察窗或营地的小鱼缸。照顾动物使用温和日常动作，没有伤口、笼子或惊吓情节。

每步都有中文故事引导、英文情境、慢速跟读、轮到孩子的提示、立即英文表扬、动作和中文结果。上方六个动物头像逐个点亮；三颗星光奖励阶段完成。默认纯语音模式下不出现选择题或下一题按钮。

新增 **21 个美术资源**：3 张 1600×900 WebP 背景、6 只动物、6 个专门姿态、6 个配套道具；18 张切图均为 512×512 真正透明 PNG。姿态共用脚底定位，睡姿保留较低的自然轮廓，展翅图保留完整翅膀。图集分离使用真实 alpha 的独立连通区域，避免宽翅膀混入旁边的小鸭子。只做切图、缩放和定位，不以手绘背景替代生成图。

新增 **57 段 MiniMax MP3**，复用 11 段，68 项生成清单齐全。每个目标都有普通、慢速版本，中文引导和中文结果也使用本地生成语音。凭据只在忽略的 .env 中，运行时只播放本地音频。

    node --experimental-strip-types scripts/generate-voice.ts --levels=6
    node --experimental-strip-types scripts/generate-voice.ts --levels=6 --dry-run

动作、姿态渐变、特效和延迟使用 Phaser 场景时间，家长暂停时冻结，重新开始清空朋友进度，切回换装关或旧关时释放动物对象。对应检查加入 tests/themes.spec.ts，验证结果记录在 docs/verification.md。

声音模式沿用本地声音活动检测：孩子开口后执行当前提示的动作，不识别具体词句，不评测发音，不保存或上传录音。完整流程自动化使用模拟声音，真实 MP3 的解码与暂停播放另行检查；不代表真实幼儿和实物麦克风的试玩结果。
