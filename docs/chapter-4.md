# 第四章：玩具城堡 · My Toys

日期：2026-10-04。主题沿用用户提供的 Big Fun 1 · Unit 4 My Toys 安排，玩法和台词为本项目原创编排。13 次语音互动，家长选择第四关并允许麦克风后，孩子全程跟读，游戏自动继续。

## 故事和英语

团团的玩具们想去彩虹街游行，可是有的还在睡觉，车站的轨道也缺了一段。孩子先叫醒玩具，再用积木修桥、请小汽车试路，最后带玩具乘火车到游行街。

六个主题词：ball / teddy bear / doll / blocks / car / train。
两类短句：It's my ___. / I like my toys.

第一幕认识玩具，第二幕将词语变成修桥、开车和载客的能力，第三幕用新动作复习。再次说 Ball，不会重复第一幕的弹跳奖励，而是传球或跳出彩纸雨。汽车第一次试路，第二次载着小熊出发。

每步都有简短中文情境引导、英文情境句、慢速目标示范、开口后的英文表扬与中文结果解说。Good / Great job / Well done / Amazing / Cool / You did it 轮换使用。表扬和动画立刻开始，播音与动作结束后才会继续。

难度按三个短词或词组 → 一句短句 → 新动作 → 熟悉词复习推进，不要求三岁孩子读文字、操作鼠标、理解长对话或接受计时压力。动作、反馈和过场期间暂停声音监听。本地声音活动检测只触发当前提示的玩具能力，不辨识内容或评判发音。

## 美术与动画

三个场景采用不同空间和配色：

- 惊喜玩具屋：珊瑚粉、柠檬黄、巨型玩具箱、积木塔，明亮室内。
- 齿轮火车站：蓝绿与黄铜、圆顶、齿轮、星灯隧道、窗外蓝色黄昏。
- 彩虹游行街：晴天户外、糖果色小屋、彩虹拱门、彩旗和宽阔街道。

使用内置 image_gen 生成 3 张背景、1 张六格透明玩具图集和 1 张配套车厢。归一化后，生产资源为 3 张 1600×900 WebP 和 7 张 512×512 RGBA PNG，共 10 张。玩具的轮廓、材质和形状差异明显：圆球、绒毛小熊、布玩偶、发条汽车、短火车和木积木；车厢作为载客道具，不增加要学习的新词。透明切图不带地面背景，底部定位统一。

资源目录：public/assets/toys/。原图：docs/art-source/toys-*.png。
完整提示词与来源：docs/toy-art-prompts.json。裁切脚本：scripts/normalize-toy-assets.py。
技术清单：public/assets/toys/manifest.json、asset-checks.json。素材联系表：docs/toy-assets-contact.jpg。

动画采用场景时间控制的弧线、弹跳、影子缩放、旋转、拼装、烟雾、载客和粒子。轨道、桥梁和彩纸等简单活动部件由 Phaser 实时绘制；主体玩具、车厢和地图使用生成图。载客时将球、小熊和玩偶放在车厢前沿的后面，汽车让小熊坐稳，并使用不同的前后位置避免与停靠火车挤在一起。暂停会冻结场景时间，换关和重玩会清理道具、计时器与补间。减少动态效果时减少弹跳幅度、粒子数量和摇摆。

## MiniMax 音频

本章离线新增 57 条 MP3，复用 11 条已有语音；生成清单共 68 条，包含中文引导和结果、英文情境句、目标的普通与慢速版，以及共用鼓励。声音继续沿用本地配置的 female-shaonv / speech-02-hd。前端仅加载已生成文件，API 凭据由离线脚本从本地 .env 读取。

    node --experimental-strip-types scripts/generate-voice.ts --levels=4 --dry-run
    node --experimental-strip-types scripts/generate-voice.ts --levels=4

生成文件、文本、模型、音色和时长写入 public/assets/audio/voice-report.json；播放索引在同目录 manifest.json。
