## 幼儿语音流程

简短中文说明 → 英文情境句 → 慢速英文目标 → 留出提示音消退时间 → 本地声音活动检测 → 场景动作和英文表扬 → 中文结果语音 → 自动继续。
家长选关、开始并允许麦克风后，孩子不点击、不按键。没有计时压力、发音评分和内容判断。动作邀请是游戏引导，不宣称摄像头或麦克风识别孩子是否真的摸鼻子、拍手或踏步。

奖励记录参与，语音说 Good / Great job / Well done / Amazing / Cool；不用“说对了”评价发音。静音、暂停、恢复、重新示范和家长试玩入口沿用引擎。

## 生成美术

使用内置 image_gen，保存 6 张 1600×900 WebP 背景和 18 张 512×512 RGBA 切图：

- public/assets/body/：3 张背景、6 个团团姿态。
- public/assets/family/：3 张背景、5 位家人、1 个镜框。
- public/assets/themes/：礼物、故事书、爱心气球、相机、铃铛、蝴蝶，以及清单和透明通道检查。
- 原图：docs/art-source/；完整提示词：docs/theme-art-prompts.json。
- 裁切和定位：scripts/normalize-theme-assets.py；联系表：docs/theme-assets-contact.jpg。

最初生成的两张雪地场景在用户反馈后被弃用。最终采用室内 / 音乐房 / 天空 / 草地 / 夜景等明显不同的空间，保留软圆形状、毛绒质感和柔和光照作为共同风格。

动作采用已有 Phaser 时间轴、姿态渐变、呼吸、轻微摇摆、脚印、弧线和粒子；泡泡、脚印、提示圈等由引擎实时绘制。没有新增整屏闪白、震屏或紧张战斗。减少动态效果时降低持续动作和粒子。过场、播音期间不监听儿童声音。

## MiniMax 语音

本轮真实调用 MiniMax，新增 80 条 MP3；已有音频直接复用。第二、三关的语音清单共 121 条（包括正常 / 慢速目标、两关台词、中文引导和反馈、共用鼓励）。音频在 public/assets/audio/，每句索引保留中文和英文字符，避免中文台词键碰撞。

生成配置继续沿用本地 .env 的 female-shaonv / speech-02-hd；前端只加载 MP3，不携带密钥或请求 MiniMax。脚本遵循 [MiniMax 同步语音接口](https://platform.minimax.io/docs/api-reference/speech-t2a-http)，默认使用国内官方 HTTPS 端点。新增条目的音色、模型、文本、文件大小及接口返回时长写入 voice-report.json。

离线补齐新台词：

    node --experimental-strip-types scripts/generate-voice.ts --levels=2,3

先查看缺多少文件：

    node --experimental-strip-types scripts/generate-voice.ts --levels=2,3 --dry-run

脚本每生成一条立即保存索引，支持中断后继续。凭据只读 .env / 进程环境变量；.env 已在 .gitignore 中。游戏运行时不使用云端评测，不上传或保存孩子录音。
